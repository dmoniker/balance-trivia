# TriviaBalance

**Open source web app · free for seniors** — play at [triviabalance.com](https://triviabalance.com).

A balance approach to trivia games: test your knowledge across various categories while improving your physical balance. Built especially for seniors — no account, no paywall, just open the site and play.

**Next level in this theme:** **BuddyLine** — a voice-first AI companion seniors reach on the phone they already have (no app install).

## Description

TriviaBalance improves balance over time. Each round is two minutes long and can be played daily to build stability and trivia knowledge.

## Features

- Two levels of balance exercises (tandem and single-leg)
- Answer as many trivia questions as you can in two minutes
- Switch legs on every wrong answer
- Responsive web — phone, tablet, or desktop

## Technologies

- Plain HTML, CSS, and JavaScript
- Trivia from local `.js` question banks (hundreds of questions, randomly presented)
- Deployed at [triviabalance.com](https://triviabalance.com)
